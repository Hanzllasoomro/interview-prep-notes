# Code of Conduct

## Our Pledge

We are committed to creating a welcoming, respectful, and inclusive community for everyone.

This project exists to help people prepare for interviews, improve their careers, and share knowledge freely. We welcome contributors of all backgrounds, experience levels, countries, cultures, identities, and perspectives.

## Expected Behavior

All contributors, maintainers, and community members are expected to:

- Be respectful and professional
- Use welcoming and inclusive language
- Accept constructive feedback gracefully
- Focus on helping others learn
- Respect different levels of experience
- Give credit when using someone else’s work
- Keep discussions relevant and productive

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment, threats, or personal attacks
- Offensive, discriminatory, or hateful language
- Trolling, insults, or disrespectful comments
- Sharing private, confidential, or leaked interview material
- Posting spam, advertisements, or unrelated content
- Copying copyrighted or paid content without permission
- Publishing someone else’s personal information
- Repeatedly ignoring maintainer instructions

## Content Standards

Contributions should be:

- Helpful for interview preparation
- Clear and well-organized
- Original or properly credited
- Free from confidential company information
- Respectful toward companies, candidates, and interviewers
- Safe for public open-source use

## Reporting Issues

If you notice behavior that violates this Code of Conduct, please report it by opening an issue or contacting the project maintainers.

When reporting, include:

- A clear description of the issue
- Links, screenshots, or references if available
- Any relevant context

Maintainers will review reports fairly and take appropriate action.

## Enforcement

Maintainers may take action when this Code of Conduct is violated. Actions may include:

- Giving a warning
- Requesting edits to content
- Closing issues or pull requests
- Removing harmful content
- Temporarily or permanently banning contributors from the project

## Maintainer Responsibility

Project maintainers are responsible for applying this Code of Conduct fairly and consistently. Maintainers should not abuse their position or treat contributors unfairly.

## Scope

This Code of Conduct applies to all project spaces, including:

- GitHub issues
- Pull requests
- Discussions
- Documentation
- Community channels
- Any public communication related to this project

## Our Goal

The goal of this community is simple:

To help people around the world prepare for interviews through free, open, high-quality, and ethical knowledge sharing.
