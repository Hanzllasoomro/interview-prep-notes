# Contributing Guide

Thank you for contributing to Global Interview Preparation Notes.

## Before You Contribute

Please check whether a similar note already exists. If it does, improve the existing note instead of creating a duplicate.

## How to Add Notes

1. Fork this repository
2. Choose the correct folder
3. Add your note using the provided template
4. Create a pull request
